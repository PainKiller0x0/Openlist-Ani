# 内置追番入口

OpenList-Ani 启动后，直接访问服务根地址即可使用内置页面。页面提供两条最小工作流：

1. **RSS 订阅**：粘贴 Mikan 等来源的 RSS 地址。页面会先在独立弹窗中识别番剧、显示 TMDb 信息、LLM 改名结果、实际下载目录，并列出排除规则生效后的下载预览；点击确认后才保存配置并立即更新追踪器。之后的新条目按 `rss.interval_time` 自动进入下载流程。页面会显示订阅是否运行中、最近一次扫描、下一次扫描，并支持“立即扫描”、暂停/恢复、修正 RSS 和删除订阅。
2. **上传种子**：选择 `.torrent` 文件，可选填写名称。服务会解析种子并创建现有 OpenList 离线下载任务，目标目录和重命名规则仍由 `[openlist]` 配置决定。

RSS 页面提供两层标题排除：

- **全局排除规则**：在“设置”弹窗中维护，对所有 RSS 生效。
- **单个 RSS 排除规则**：只对当前订阅生效。

输入框支持用 `|` 分隔多个规则，例如 `ABEMA|CR|Baha`。规则按正则匹配标题；如果正则本身包含括号内的 `|`，也会被保留为一个规则。预览中的“排除后会下载”是标题过滤结果，实际扫描还会继续应用清晰度优先级、已下载去重和严格模式。已有订阅不再在主卡片上编辑单 RSS 规则，需要点击“修正 RSS”进入修正弹窗。

“设置”弹窗还可以维护 LLM 提供商、Base URL、模型、API Key、TMDB 语言和元数据解析器。API Key 不会回显，留空保存会保留现有值；LLM/解析器修改需要重启服务后生效。

页面不保存额外的账号或网盘凭据，仍使用原有的 OpenList-Ani 配置和鉴权。上传的种子保存在 `data/uploads/`，用于让 OpenList 在任务执行期间访问；可以按需清理已经完成且不再需要的种子文件。

如果服务通过反向代理暴露，反向代理只需要把根路径和 `/api/*` 一起转发到 OpenList-Ani 后端；`/docs` 仍然是原有的 API 文档入口。
